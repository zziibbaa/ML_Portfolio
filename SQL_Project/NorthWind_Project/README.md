# 🏢 Northwind SQL Analysis Project

A SQL project based on the Northwind sample database designed to practice both fundamental and advanced SQL concepts using real-world business data.

The project consists of 30 SQL exercises covering data retrieval, filtering, aggregation, joins, subqueries, grouping operations, and business-oriented analytical queries.

# 📊 Dataset

The project uses Microsoft's Northwind sample database.

Northwind simulates the operations of an international trading company and contains information related to:

- Customers
- Orders
- Employees
- Products
- Suppliers
- Categories
- Order Details
- Shipping Information

The dataset provides realistic business scenarios suitable for practicing SQL querying and analytical techniques.
