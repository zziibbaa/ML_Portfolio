# 🌧️ Rainfall Trends in India Analysis with Python

تحلیل بارش در هند از سال 1901 تا 2015 با استفاده از داده‌های تاریخی

## 📌 هدف پروژه

- بررسی روند بلندمدت بارش در هند
- شناسایی سال‌های خشک یا پر بارش
- تحلیل فصلی بارش و ارتباط آن با بارش سالانه


## 📁 داده‌ها

- Dataset: [rainfall_area-wt_India_1901-2015.csv](https://amanxai.com/wp-content/uploads/2024/11/rainfall_area-wt_India_1901-2015.csv)
- شامل داده‌های ماهانه، فصلی و سالانه بارش در هند از سال 1901 تا 2015

### ویژگی‌های مهم:

| ستون‌ها | توضیح |
|--------|-------|
| REGION | منطقه (هند) |
| YEAR | سال |
| JAN-DEC | بارش ماهانه |
| ANNUAL | بارش سالانه |
| Jan-Feb, Mar-May, Jun-Sep, Oct-Dec | بارش فصلی |

## 📊 مراحل تحلیل

1. **تحلیل روند سالانه**: بررسی تغییرات بارش سالانه نسبت به میانگین
2. **تحلیل ماهانه**: میانگین بارش هر ماه در طول سال‌ها
3. **تحلیل فصلی**: بررسی سهم هر فصل در بارش سالانه
4. **میانگین متحرک ۱۰ ساله**: برای بررسی اثرات تغییرات اقلیمی
5. **شناسایی سال‌های خشک و پر بارش**: با استفاده از انحراف معیار


## 🛠 ابزارها و تکنولوژی‌ها

- Python
- Pandas, Matplotlib, Seaborn
- Jupyter Notebook

## 📈 نتایج کلیدی

- فصل بارانی (ژوئن تا سپتامبر) بیشترین سهم را در بارش سالانه دارد (حدود 890mm)
- سال‌های خشک بیشتر در نیمه دوم قرن دیده می‌شوند
- همبستگی بارش فصلی با سالانه: Monsoon (0.93) > Oct-Dec (0.53) > Mar-May (0.31) > Jan-Feb (0.23)
