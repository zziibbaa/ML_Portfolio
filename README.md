## 🚀 دیپلوی مدل‌ها (API)

📁 مسیر پروژه: `MyProject/05_Deployment/`

### Deployment Pipeline

```
Training Script
      ↓
Saved Model (.pkl)
      ↓
FastAPI Endpoint
      ↓
Docker Container
      ↓
Client Request / Swagger UI
```

---

### ویژگی‌ها

- RESTful API با FastAPI و Flask  
- مستندسازی خودکار با Swagger  
- استفاده از Pipeline برای پیش‌پردازش  
- تست با pytest  
- اجرای کانتینری با Docker
