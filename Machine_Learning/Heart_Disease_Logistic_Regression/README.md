# ❤️ پیش‌بینی بیماری قلبی با Logistic Regression

این پروژه با هدف تحلیل داده‌های بیماران و پیش‌بینی احتمال ابتلا به بیماری قلبی انجام شده است. داده‌ها از منبع معتبر [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/Heart+Disease) دریافت شده‌اند و شامل اطلاعات پزشکی و بالینی بیماران هستند.

---

## 📁 منبع داده

- **نام دیتاست:** Heart Disease Dataset  
- **لینک:** [UCI Repository](https://archive.ics.uci.edu/ml/datasets/Heart+Disease)  
- شامل ویژگی‌هایی مانند سن، فشار خون، کلسترول، نوار قلب، ضربان قلب، و غیره

---

## 📌 مراحل انجام‌شده در پروژه

### 1. 📊 تحلیل اکتشافی داده‌ها (EDA)

- بررسی توزیع ویژگی‌ها و متغیر هدف  
- تحلیل روابط بین ویژگی‌ها با استفاده از نمودارهای بصری  
- بررسی داده‌های پرت و مفقود  
- آماده‌سازی داده‌ها برای مدل‌سازی (استانداردسازی، تبدیل متغیرها، و تقسیم داده‌ها)

### 2. 🧠 ساخت مدل Logistic Regression با Cross-Validation

- استفاده از Logistic Regression برای مدل‌سازی احتمال ابتلا به بیماری قلبی  
- اعمال Cross-Validation برای ارزیابی عملکرد مدل به‌صورت پایدار  
- استخراج ضرایب مدل برای تحلیل اهمیت ویژگی‌ها

---

## 📈 تحلیل اهمیت ویژگی‌ها

با استفاده از ضرایب مدل، اهمیت هر ویژگی در پیش‌بینی بیماری قلبی بررسی شده است:

- ضرایب مدل به‌صورت یک سری مرتب‌شده نمایش داده شده‌اند  
- رسم نمودار میله‌ای برای نمایش تأثیر هر ویژگی بر خروجی مدل  
- استفاده از رنگ‌بندی برای نمایش شدت تأثیر (مثبت یا منفی)

---

## 🧪 ارزیابی مدل

### ✅ منحنی ROC

- رسم منحنی ROC برای بررسی توانایی مدل در تفکیک کلاس‌ها  
- محاسبه AUC برای سنجش کیفیت کلی مدل  
- بررسی تعادل بین نرخ مثبت واقعی و نرخ مثبت کاذب

### ✅ منحنی Precision-Recall

- رسم منحنی Precision-Recall برای بررسی دقت مدل در پیش‌بینی کلاس مثبت  
- مناسب برای داده‌هایی با عدم‌تعادل در کلاس‌ها  
- تحلیل trade-off بین precision و recall در سطوح مختلف آستانه تصمیم‌گیری

## 📝 نتیجه‌گیری

مدل Logistic Regression توانسته با دقت قابل‌قبول، احتمال ابتلا به بیماری قلبی را پیش‌بینی کند. تحلیل ضرایب مدل نشان می‌دهد که برخی ویژگی‌ها مانند سن، فشار خون، و نتایج نوار قلب تأثیر قابل‌توجهی در پیش‌بینی دارند. نمودارهای ROC و Precision-Recall نیز نشان‌دهنده عملکرد مناسب مدل در تفکیک بیماران مبتلا و غیرمبتلا هستند.
